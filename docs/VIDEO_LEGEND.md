## How to read any plot we make


### Warmth vs Sentiment (`warmth_vs_sentiment.png`)
- **x = Warmth v2** `happy*0.9 + neutral*0.25 - fear*0.15 - sad*0.10 +35` (0-99, 7 frames, fallback Retina→OpenCV→MTCNN). Mean 63.1, median 57.2 (n=24 scored, 50 pending). Old v1 `happy*1.2+neutral*0.5+30` inflated to 71.2.
- **y = Vocal Sentiment** TextBlob -1…1 on Whisper tiny transcript (>0.10 = optimistic). Bios are flat (0.064), videos optimistic (0.14).
- **Color = Warmth** (Blues), **labels = shorthand** for top 3. Dashed lines: `warmth=70`, `sentiment=0.10`.
- **Read:** Top-right = warm + optimistic (the ‘pitch’). Bottom-left = flat/serious. We plot 74 dots; 50 are grey pending until `make transcripts`.

### Charisma by Cohort (`charisma_by_cohort.png`)
- Box/strip per cohort (2018→2027). y=Warmth v2. n per box = `yt_cohort` (§ below). 2017 has 0 videos (no box). Use shorthand jittered dots to spot outliers: e.g. `AB27` (Anita Bassey 97.3) top, `LH22` (Lena Hoffmann 41.0) bottom.

### How Schwarzman plays *vs others*
- **Videos are not a sample of all Schwarzman scholars** — they’re 74/1497 = 4.9% who published. So “vs others” means two comparisons we make explicit in every plot caption:
  1. **Schwarzman video sharers vs all Schwarzman (1497)** — to flag bias.
  2. **Schwarzman vs generic elite fellowship** — no external dataset here, so we anchor to program mission: US 41% + CN 20% = bridge (vs Rhodes general). Our `region` field lets you compare US/CN/Other directly.

## Using the legend to make plots (one-liner)

```python
import pandas as pd
legend=pd.read_csv('data/video_legend.csv')  # shorthand, vid, region, cohort
meta=pd.read_json('data/meta/AB27.json')     # or fallback: warmth_vs_sentiment from ADMITTED_SCHOLAR_PROFILES.md
# join
plot_df=legend.merge(meta, on='vid', how='left')  # shorthand stays as label
# then
plt.scatter(plot_df['warmth_v2'], plot_df['sentiment'], c=plot_df['region'].map({'US':'#0ea5e9','CN':'#ef4444', ...}))
for _,r in plot_df.iterrows(): plt.annotate(r['shorthand'], (r['warmth_v2'], r['sentiment']), fontsize=7)
```


> **Note:** `SL26` (Stephanie Lin 2026, Harvard) and `SL27` (Stephanie Li 2027, Duke Kunshan) share `imwXwnyzpRU` in the CSV — one YouTube intro is listed twice. Counts above treat them as 2 scholars, 1 unique vid (73 unique vids for 74 rows). Pipeline deduplicates by `vid`.
